# Không upload ZIP này trực tiếp lên GitHub

ZIP này chỉ chứa các file môn học để giảng viên overlay lên kho template chính thức và để sinh viên tham khảo.

## Sinh viên
1. Mở link kho mẫu chính thức trên LMS.
2. Bấm **Use this template → Create a new repository**.
3. Sửa các file của đề trong repo vừa tạo.
4. Kiểm tra tab **Actions** có workflow.

Nếu Actions trống, dừng và báo mentor.
